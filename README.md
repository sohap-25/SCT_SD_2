# SCT_SD_2

## Guess The Number Game

A Java GUI-based Guess The Number game that generates a random number and allows users to guess it with interactive hints using Swing in VS Code.

## Technologies Used
- Java
- Swing GUI
- VS Code

## Features
- Random number generation
- User-friendly GUI
- Hints for high and low guesses
- Restart game option
- Tracks number of attempts

## How to Run

1. Open the project in VS Code

2. Compile the program:

```bash
javac GuessTheNumberGame.java
```

3. Run the program:

```bash
java GuessTheNumberGame
```

4. The game window will open and you can start guessing the number.
